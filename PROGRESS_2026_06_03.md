## Phase 2A: UWM Image/Action-Only Eval Fixes

### Bugs Found
1. **agent_pos normalization mismatch**: Training (`PushTDataset.__getitem__`) normalizes agent_pos via `lowdim_normalizer` (min/max → [-1,1]), but eval (`eval_pusht.py`, `eval_pusht_dp.py`) passes raw [0,512] agent_pos directly without normalization.

2. **clip_sample**: Not actually a bug for MinMax-normalized actions (range is already [-1,1]), but `clip_sample=False` shows small additional benefit.

- `outputs/dp_pusht/run_20k_bs64/latest.pt` — NO lowdim_normalizer in checkpoint

## Architecture Difference Summary (Root Cause)

| | TransformerForDiffusion (0.998) | UWM AdaLN-DiT (0.42-0.44) |
|---|---|---|
| Self-attention | **Causal** | Bidirectional |
| Obs conditioning | **Cross-attention** (obs as memory tokens) | **AdaLN modulation** (obs as scale+shift gate) |
| Time embedding | Separate token in condition sequence | Concatenated with global_cond |
| EMA | 0.9999 | None |
| LR | Cosine + warmup | Constant |
| Inf steps | 100 (DDPM) | 10 (DDIM) |
| Weight decay | 0.1 | 1e-6 |
| Betas | (0.9, 0.95) | (0.9, 0.999) |
