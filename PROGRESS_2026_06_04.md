## Phase 9: R1 — EMA Ablation

### Method
Did NOT retrain from scratch. Retroactively added EMA to the existing converged DP-only C checkpoint (`outputs/dp_pusht/run_20k_bs64/latest.pt`):
1. Load converged model at step 20000
2. Continue training 500 steps with EMA (decay=0.9999)
3. Save both raw and EMA weights
4. Evaluate both on same 50 seeds 100000-100049

### Results

| Weight | Mean | Median | Std | ep>0.5 |
|--------|------|--------|-----|--------|
| raw (20.5k, fine-tuned) | 0.354 | 0.386 | 0.333 | 19/50 |
| **EMA** | **0.397** | **0.423** | **0.345** | **22/50** |
| Baseline DP-only C (no fine-tune, step 20k) | 0.391 | 0.391 | 0.346 | 17/50 |

### Conclusion
EMA gives at best +0.006 improvement over baseline. **EMA is not the main gap** between our 0.39 and official DP's 0.95.

## Architecture Difference Summary

| | Official DP Image (0.949) | Our DP-only C (0.391) |
|---|---|---|
| Diffusion backbone | **UNet 1D** (3 levels, 512-2048 ch) | Transformer (12L/768E/12H) |
| Conditioning | **Global feature** (obs→linear→cond) | AdaLN modulation (scale+shift gate) |
| Self-attention | N/A (UNet conv) | Bidirectional |
| Vision encoder | ResNet-18 (ImageNet pretrained) | ResNet (from scratch) |
| Obs integration | Feature concat with action | Conditioned via AdaLN gate |
| Normalizer | LinearNormalizer (mean/std-like) | MinMax (scale=[242,242] etc) |
| Inf steps | 100 DDPM (train) / 10 DDIM (eval) | 10 DDIM |
| EMA | 0.9999 | None → adding gives +0.006 |
| LR | Cosine + warmup (likely) | Constant 1e-4 |
| Params | 252M | ~150M |

## Conclusions

1. **clip_sample / normalizer bug** explains the early ~0.1 low scores. Fixing to Config C (norm_agent_pos=True, clip_sample=False) brought scores to 0.39-0.43.

2. **UWM joint C vs DP-only C**: UWM has slight mean advantage (+0.043) but paired median Δ = 0, UWM wins 24 vs DP wins 16. All three statistical tests are non-significant. **Video loss neither helps nor hurts** in the AdaLN-DiT setting.

3. **EMA provides negligible benefit**: +0.006 mean improvement. Not the main gap.

4. **The main gap is 0.95 (official UNet) vs 0.39 (our Transformer/AdaLN)**. This 0.56 gap cannot be explained by EMA, LR schedule, or normalizer differences. The root cause is architectural: UNet-based global conditioning vs Transformer-based AdaLN conditioning.

5. **Next priority**: Replace the AdaLN conditioning with cross-attention conditioning (TransformerForDiffusion style), keeping the same image encoder and training data. Only after the image-based DP reaches >0.6 should we return to UWM joint with video loss.
